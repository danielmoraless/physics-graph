# Asignación FIS 115: Gráficas con Matplotlib
Este repositorio contiene el código empleado por la mesa 4 de laboratorio para graficar los datos de la asignación del martes, 3 de junio de 2025.

# Inicialización de entorno virtual
- Dentro de la carpeta del repositorio, crear el virtual environment.
```bash
python -m venv .
```

- Una vez creado, inicializar el entorno.
Windows:
```ps1
.\Scripts\Activate.ps1
```
MacOS:
```bash
chmod +x ./Scripts/activate.fish
./Scripts/activate.fish
```
Linux:
```bash
chmod +x ./Scripts/activate
./activate
```

# Instalación de dependencias
```bash
pip install -r requirements.txt
```

# Producción de gráficas
Para visualizar las gráficas, solo debe ejecutar el archivo que corresponda.
```bash
python pendulo.py # Ejemplo
```
